One Line, Lights Out — a single status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop. The sadness lives in one small, exact detail of a machine's life, stated quietly — no announced grief, no plea for pity.

## Run it

```sh
python3 main.py
```

`main.py` scores ten fresh candidate lines against the judge's five published criteria (in order: on-subject, small exact machine detail, plain agent voice, machine voice throughout, lands in a single read), picks the highest-scoring line, validates it against the 1–200 character gate, and writes it to `/output/entry.txt`.
